* Behaviors

Custom hold-tap and tap-dance behaviors used across the keymap.

- ~hm~ :: homerow mods, tap-preferred, 200ms tapping term.
- ~td_aoe4~ :: tap-dance on the outer thumb key; a single tap does nothing, a second tap toggles the =AOE4= layer.
- ~aoe4_toggle_flash~ :: macro invoked by ~td_aoe4~ instead of a bare ~&tog AOE4~. It toggles the layer, then flashes the per-key RGB for 250ms as confirmation. Because ~&tog~ is a toggle, the same flash fires on the way in and on the way out -- it means "the switch happened", not "AOE4 is on".

  The flash is two ~RGB_TOG~ inversions 250ms apart rather than an on/colour/off sequence. ~RGB_TOG~ is *relative*, so the underglow always lands back on whatever state it started in -- there is no need to read the current state (which a keymap macro cannot do) and no hardcoded assumption about whether underglow normally rests on or off. It is visible either way: resting-off blinks bright, resting-on blinks dark.

  Consequences of doing it this way: the flash takes the saved colour and effect instead of a fixed red, and nothing about hue, saturation, brightness or effect is overwritten. The two ~RGB_TOG~ calls each schedule a debounced settings save, but they cancel out, so the value written 60s later is the one that was already stored.

#+begin_src c
    behaviors {
        hm: homerow_mods {
            compatible = "zmk,behavior-hold-tap";
            #binding-cells = <2>;
            tapping-term-ms = <200>;
            quick-tap-ms = <50>;
            flavor = "tap-preferred";
            bindings = <&kp>, <&kp>;
        };

        td_aoe4: tap_dance_aoe4 {
            compatible = "zmk,behavior-tap-dance";
            #binding-cells = <0>;
            tapping-term-ms = <300>;
            bindings = <&none>, <&aoe4_toggle_flash>;
        };
    };

    macros {
        aoe4_toggle_flash: aoe4_toggle_flash {
            compatible = "zmk,behavior-macro";
            #binding-cells = <0>;
            wait-ms = <0>;
            tap-ms = <0>;
            bindings =
                /* Do the actual layer toggle first so the flash never delays it. */
                <&tog AOE4>,
                /*
                 * Flash by inverting the underglow for 250ms, then inverting
                 * back. RGB_TOG is relative, so this restores whatever the
                 * previous on/off state was without needing to read it: off
                 * blinks bright, on blinks dark. Colour, effect, brightness
                 * and saturation are never touched.
                 */
                <&macro_wait_time 250>,
                <&rgb_ug RGB_TOG>,
                <&macro_wait_time 0>,
                <&rgb_ug RGB_TOG>;
        };
    };

    keymap {
        compatible = "zmk,keymap";
#+end_src

* Base layer

Default typing/navigation layer. Thumb access to numbers, symbols, admin, hyper, AOE4, and function keys. The upper-left-middle thumb key is a plain ~&mo FUNCTION~. The bottom-right pinky key (right shift's position on a standard layout) is the sole ~td_aoe4~, matching its placement on the old Tomahawk keymap: double-tap it to toggle =AOE4=.

#+begin_src c
        default_layer {
            bindings = <
&kp EQUAL  &kp N1        &kp N2        &kp N3        &kp N4        &kp N5       &kp N6        &kp N7         &kp N8       &kp N9       &kp N0        &kp MINUS
&kp TAB    &kp Q         &kp W         &kp E         &kp R         &kp T        &kp Y         &kp U          &kp I        &kp O        &kp P         &kp BSLH
&lt NUMBERS CAPS  &hm LGUI A    &hm LALT S    &hm LCTRL D   &hm LSHFT F   &kp G        &kp H         &hm RSHFT J    &hm RCTRL K  &hm LALT L   &hm RGUI SEMI &kp SQT
&kp LSHFT  &kp Z         &kp X         &kp C         &kp V         &kp B        &kp N         &kp M          &kp COMMA    &kp DOT      &kp FSLH      &td_aoe4
                      &kp LGUI      &kp LALT                                                           &kp LBKT      &kp RBKT
                                                  /* upper-left */  &kp LC(LA(LS(LGUI)))  &mo FUNCTION  &mo ADMIN
                                                  /* upper-right */ &none  &none  &none

        };
#+end_src

* AOE4 layer

Port of the old Tomahawk Age of Empires IV layer. Keeps the legacy game layout and toggle behavior. Toggled on/off via ~td_aoe4~ (double-tap the upper-right thumb key on the base layer, or the lower-right pinky key on this layer).

** Command reference

if these have been remapped). The build menu is organized by Age tab
(Q/W/E/R), and A/S/D/F/G/Z/X/C/V/B select a building within whichever
tab is open.

* Trackballs

** Right trackball

Cursor movement, with temporary mouse-button layer activation.

#+begin_src c
&trackball_peripheral_listener {
    input-processors =
        <&zip_temp_layer AUTO_MOUSE 500>;
};
#+end_src

** Left trackball

Scrolling-focused trackball with reduced sensitivity and inverted Y: sensitivity is multiplied by 1 and divided by 12 (significantly slower for scrolling), XY movement is mapped to scroll events instead of cursor movement, and vertical scrolling is inverted so the view moves in the same direction as the top of the trackball.

#+begin_src c
&trackball_central_listener {
    input-processors =
        <&zip_xy_scaler 1 12>,
        <&zip_xy_to_scroll_mapper>,
        <&zip_scroll_transform INPUT_TRANSFORM_Y_INVERT>;
};
#+end_src
